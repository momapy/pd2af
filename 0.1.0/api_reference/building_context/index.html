    Context

    pd2af.building.context

    The shared state of the two build passes.

    BuilderContext is a plain dataclass of slots: :func:pd2af.core._build_map creates one, the model pass fills the model and the pass-1 scratch slots, and the layout pass reads them back to build the layout and the layout-model mapping. It lives in its own module so both language builders can name it in their annotations without importing the orchestrator that imports them.
